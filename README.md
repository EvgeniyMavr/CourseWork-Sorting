# Comparative Analysis of Sorting Algorithms (Bubble Sort vs Comb Sort)

This repository contains the coursework materials for the "Algorithms and Data Structures" course.

## Project Overview
This project focuses on the theoretical and experimental comparison of two sorting algorithms:
- Bubble Sort
- Comb Sort

## Repository Contents:
- main.cpp — C++ source code containing the implementation of both algorithms and execution time measurements.
- CourseWork.pdf — Full coursework report including theory, graphs, and conclusions.
- Presentation.pdf — Defense presentation slides.
- results.xlsx — Spreadsheet with experimental data and results.

## Experimental Results
The research was conducted on arrays ranging from 10 to 10,000 elements. The time measurements revealed that for an array of 10,000 elements, Comb Sort is almost 200 times faster than Bubble Sort (0.007 seconds vs. 1.44 seconds). This empirically confirms the theoretical time complexity difference of O(N²) and O(N log N).
